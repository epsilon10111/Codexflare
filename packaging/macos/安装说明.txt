Codexflare macOS 安装说明（main 源码构建）

适用范围
main 源码支持 Apple Silicon（arm64）的两套精确构建：Codex 26.1013.31256 / build 20586、26.1021.31345 / build 21828。20586 已在 macOS 26.6.2 原生验证；21828 保留上游适配，本轮仅复测逻辑和归档，不代表重新完成原生验收。
目标应用为 /Applications/ChatGPT.app 或 /Applications/Codex.app。
不包含 OpenAI 应用；需先自行安装上述兼容构建。Intel、其他 build 和其他 macOS 版本不在本次验证范围。已发布的 v0.1.1 DMG 仍仅支持 20586；Linux 包仍从 v0.1.0 Release 下载。

下载校验
build 20586 用户可从 https://github.com/epsilon10111/Codexflare/releases/tag/v0.1.1 下载已发布 DMG 与同名 .sha256 文件。在下载目录执行：
  shasum -a 256 -c Codexflare-0.1.1-macOS-arm64-build20586.dmg.sha256

从 main 源码自行构建的文件名为 Codexflare-<版本>-macOS-arm64.dmg，使用构建时生成的同名 .sha256 校验。其构建信息列出两套 targets 与源码提交；不要将它当作原 v0.1.1 Release 附件。

安装
1. 打开 DMG，将 Codexflare.app 拖到 Applications（应用程序）。
2. 等待复制完成，从“应用程序”打开 Codexflare；不要直接从只读 DMG 内运行。
3. 包内已包含 Python / PyObjC，不包含 FFmpeg。默认动画可直接播放，两张默认背景已预缩到 3840×2160 范围内，无需另装媒体工具即可使用。
4. 此包使用本地 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。首次打开如遇未验证开发者提示，核实包的来源后，可按 Apple 官方说明在“隐私与安全性”中为该 App 选择“仍要打开”。保持系统的全局安全保护开启。

从源码版迁移
如果之前已经用源码版的原入口模式修改了原 ChatGPT，先在原编辑器点击“恢复原版 ChatGPT”，用 Cmd+Q 彻底退出 ChatGPT，等待恢复完成，再使用 DMG 版。新安装不会接管旧版状态；不要把旧 original-install.json 或官方备份搬进打包版的数据目录。只使用过源码独立副本模式的用户无需恢复原应用。

自定义媒体需要 FFmpeg
导入自定义视频需要 FFmpeg 和 ffprobe；对新图片进一步缩图也需要 FFmpeg。
已经安装 Homebrew 的用户可在终端运行：
  brew install ffmpeg
未使用 Homebrew 的用户可从 FFmpeg 官方下载页选择 macOS 构建：
  https://ffmpeg.org/download.html
安装后重新打开 Codexflare。应用会在 /opt/homebrew/bin、/usr/local/bin 及已有 PATH 中查找媒体工具。

允许修改 App：权限应给谁
打开“系统设置”→“隐私与安全性”（部分系统显示“隐私与安全”）→“App 管理”。
Apple 将该权限定义为允许 App 更新或删除其他 App。

• 如果由 ChatGPT 内的任务执行安装或更新，为 ChatGPT 开启“App 管理”权限。
• 如果从“应用程序”直接运行本 DMG 的 Codexflare，由 Codexflare 发起备份、修改和恢复，应为 Codexflare 开启该权限。
• 两种执行方式的权限分别管理。仅因为 ChatGPT 是被修改的目标，并不表示只给 ChatGPT 授权就能让独立运行的 Codexflare 修改它。以系统权限弹窗显示的发起 App 名称为准。

如果列表中尚无对应 App，先在该 App 中尝试一次“应用”，按 macOS 的权限提示操作；若系统要求重新打开该 App，照提示完成后重试。“App 管理”与“自动化”“完全磁盘访问权限”不同，本安装流程不要求开启完全磁盘访问，也不要求关闭系统安全保护。

应用动画和背景
本 DMG 默认使用原入口模式：
1. 在 Codexflare 中选择动画和背景，点击“保存设置”，再点击“应用到 ChatGPT”。
2. ChatGPT 运行时会先准备候选，显示等待退出；当前会话不会被强制关闭。
3. 保存工作后，用 Cmd+Q 完全退出 ChatGPT。后台安装器完成后，仍从原来的 ChatGPT 图标启动即可看到效果。仅关闭窗口或唤起已运行进程不会重播动画。
4. 如果准备或应用失败，查看编辑器提示；检查版本和上述“App 管理”权限后重试。只有状态显示已应用，才表示安装完成。
目标应用为 Codex.app 时，退出和启动对应的 Codex 应用。

两种模式的区别
原入口模式：本 DMG 的默认模式。保留官方应用备份，退出后替换原应用路径；继续使用原来的名称、图标和默认配置路径，不建立独立账号目录。源码版可通过 tools/original_macos.py prepare 显式启用，随后运行 wait-activate 等待正常退出并安装，详见 README。
独立副本模式：源码版的默认模式，按钮显示“应用到 Codex”；完全退出定制副本后应用，再从“Codexflare Codex.app”启动。它使用单独配置，原 ChatGPT 图标不会显示定制效果。

原入口模式也会使用本地签名替换供应商签名，可能需要重新登录；依赖供应商身份的原生功能不保证兼容。原应用更新到其他 build 后需重新适配。

数据与恢复
打包版配置、素材和官方备份默认保存于 ~/.local/share/codexflare（~ 表示你的用户主目录）；若设置了绝对路径的 XDG_DATA_HOME，则使用该目录下的 codexflare。不保存在 DMG 或 Codexflare.app 中。源码版使用仓库内的 .local/。本包不携带个人设置、账号数据或应用备份。
要撤回原入口修改，在 Codexflare 点击“恢复原版 ChatGPT”，然后正常退出 ChatGPT，等待恢复完成。确认恢复后再删除 Codexflare.app；保留数据目录可保留设置和备份。

源码与依赖许可
DMG 附带与发布提交一致的 Codexflare-source.tar.gz，依赖版本见“构建信息.json”。
Python、PyObjC 和 PyInstaller runtime 的许可保存在 Codexflare.app/Contents/Resources/licenses/；其中包含 PyInstaller bootloader 分发例外。Codexflare 代码使用 MIT 许可，默认动画和背景使用独立素材许可，见 Codexflare.app/Contents/Resources/assets/LICENSE。默认背景在打包时缩图，修改说明保存在 licenses/说明.txt。
