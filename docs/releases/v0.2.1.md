# Codexflare v0.2.1

Linux、Windows、macOS 共用的稳定性缓解版本：恢复原应用的聊天布局、FooterFade 与输入区底色，移除整段会话滚动遮罩、尺寸容器及输入区模糊；背景图片和启动动画仍保留。

报告中的真实账户卡死尚未在隔离测试中复现。本次消除潜在渲染干扰，不能宣称已定位唯一根因或证明长期不再复发。测试和边界见 [VALIDATION.md](../../VALIDATION.md)。更新编辑器后须保存并重新应用，已有定制运行副本不会自动获得修复。

| 平台 | 附件 | 依赖与范围 |
| --- | --- | --- |
| Linux x86_64 | `codexflare-0.2.1-1.noarch.rpm`、`codexflare_0.2.1-1_all.deb` | Python 3.11+、GTK3/WebKitGTK；本轮应用基线 build 13536 |
| Windows x64 | `Codexflare-0.2.1-Windows-x64-source.zip` | 源码发行包，需 Python 3.13 x64 和 WebView2；运行 Codexflare.cmd，首次联网安装依赖；历史应用基线 MSIX 26.1021.3705.0 / build 21828 |
| macOS arm64 | `Codexflare-0.2.1-macOS-arm64.dmg` | 内嵌 Python/PyObjC；历史应用基线 build 20586、21828；ad-hoc 签名、未公证 |

提供 SHA256 校验、源码归档和 SRPM。包内不含官方应用、账户或 FFmpeg；自定义视频导入需 FFmpeg/ffprobe。Windows 通过私有匿名管道增强现有签名应用。macOS 原入口模式保留官方备份，在应用正常退出后替换；可能需重新登录，签名相关功能仍受限。详见 [使用指南](../guide.zh-CN.md)。

删除未使用的 MP4 原片、旧光轨示例和生成器，精简过时的阶段说明，更新三平台下载入口。旧 v0.1.0/v0.1.1 标签与附件保持不变；旧 v0.1.1 DMG 仍只支持 build 20586。
