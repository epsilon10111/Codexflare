# Codexflare v0.1.0

首个 RPM 发行版：在本地 GTK/WebKit 窗口中定制 Codex 开场动画、工作区背景和启动窗口。

## 功能

- 内置十秒开场视频和两张背景，支持导入自己的视频与 PNG。
- 调整播放速度、亮度、对比度、饱和度、适配方式和静音。
- 调整背景强度、位置、大小，主对话与分支页共享背景。
- 保存全屏、上次窗口或居中小窗口的启动方式。
- 提前准备工作区和背景，支持 Esc 跳过及失败保护。
- 使用可回退的用户副本，不修改系统应用或账户数据。

## 安装

下载 RPM 与 `SHA256SUMS` 后执行：

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo dnf install ./codexflare-0.1.0-1.noarch.rpm
codexflare
```

保存设置后，正常退出 Codex，再在 Codexflare 中刷新状态并「应用到 Codex」。安装 RPM 本身不会替换应用入口。卸载前执行 `codexflare-manage uninstall` 可恢复原入口，配置与素材保留。

## 兼容与验证

- **仅适配 Linux x86_64 Codex 26.1002.52244 / build 13536**，路径 `/usr/lib/chatgpt`。`noarch` 指编辑器包不包含本机二进制，不表示其他架构的 Codex 已适配。
- Fedora 44 KDE 环境验证：63 项 Python 测试、57 项 Node 测试通过；隔离 RPM 安装/卸载、只读代码下的配置保存及包内 GTK 窗口通过。
- RPM 不包含 Codex/ChatGPT/Electron；首版未作 GPG 签名。全新系统依赖下载、其他发行版及真实账户冷启动未验证。
- 代码采用 MIT；默认素材保留权利，按仓库中的单独许可随 Codexflare 分发。本项目与 OpenAI 无隶属或背书关系。

附件包括 RPM、可重建的源码归档、SRPM 和 `SHA256SUMS`。详细说明见仓库 README 与 VALIDATION.md。
