# Codexflare v0.1.0

首个发行版，提供 RPM 和 DEB：在本地 GTK/WebKit 窗口中定制 Codex 开场动画、工作区背景和启动窗口。

## 功能

- 内置十秒开场视频和两张背景，支持导入自己的视频与 PNG。
- 调整播放速度、亮度、对比度、饱和度、适配方式和静音。
- 调整背景强度、位置、大小，主对话与分支页共享背景。
- 保存全屏、上次窗口或居中小窗口的启动方式。
- 提前准备工作区和背景，支持 Esc 跳过及失败保护。
- 使用可回退的用户副本，不修改系统应用或账户数据。

## 安装

### Fedora

下载 RPM 与 `SHA256SUMS` 后执行：

```bash
sha256sum --ignore-missing -c SHA256SUMS
sudo dnf install ./codexflare-0.1.0-1.noarch.rpm
codexflare
```

### Debian / Ubuntu

下载 `codexflare_0.1.0-1_all.deb` 及同名 `.deb.sha256` 后执行：

```bash
sha256sum -c codexflare_0.1.0-1_all.deb.sha256
sudo apt install ./codexflare_0.1.0-1_all.deb
codexflare
```

依赖基线为 Debian 12 / Ubuntu 24.04，Ubuntu 的 FFmpeg 来自 `universe`。DEB 包含默认视频及两张背景，20 个运行文件与 RPM 完全一致。

保存设置后，正常退出 Codex，再在 Codexflare 中刷新状态并「应用到 Codex」。安装软件包本身不会替换应用入口。卸载前执行 `codexflare-manage uninstall` 可恢复原入口，配置与素材保留。
